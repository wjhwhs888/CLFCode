# CLFCode Tips 轮播条目（A5，设计-工具调用循环上限机制改造 §3.4）
# 每行一条；# 开头为注释；输入框上方请求处理中轮播显示
# 用户可自行增删条目，重启生效
# 【快捷键】
/help 查看帮助 · /context 查看上下文 · Shift+Tab 切换安全模式
Ctrl+T 展开思考过程 · Ctrl+N 换行 · Ctrl+R 折叠回显 · Esc 中断
左键拖选自动复制 · 右键或 Ctrl+V 粘贴
# 【命令】
/clear 摘要并开新会话 · /resume 恢复历史会话 · /model 切换模型
/mode 切换安全模式 · /version 查看版本 · /config 查看配置
# 【使用技巧】
复杂任务可分阶段完成，触顶后输入「继续」接着做
需要跟踪任务进度，让 agent 用 todo_write 建清单
中断后继续输入，可接着上次的工作
# 【异常处理】
长时间无响应可 Esc 中断，或输入「停止过度思考」
高危操作会弹出确认，仔细核对后选择
