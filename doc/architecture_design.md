# CLFCode 系统架构设计

## 1. 概述

CLFCode 是一个本地 AI Coding Agent，采用模块化分层架构。
用户通过 REPL 交互，Agent 通过 HTTP 调用远程 LLM API，
利用工具层（文件操作、命令执行）完成任务。

## 3. 模块职责

### main — 入口
- 解析命令行参数
- 加载配置（agent_settings.json）
- 启动 REPL 交互循环
- 协调各模块工作

### core — 核心逻辑
- **agentLoop**：Agent 主循环，管理工具调用 → API 调用 → 响应处理的完整流程
- **context**：管理对话历史和上下文窗口，处理 token 计数和截断

### tools — 工具层
- **fileOps**：readFile / writeFile / listDirectory
- **commandExec**：异步子进程管理，执行 shell 命令并捕获输出

### network — 通信层
- **httpClient**：封装 cpp-httplib，支持同步/流式 HTTP 请求，处理重试和超时

## 4. 数据流

```
用户输入 → main → agentLoop ──(build request)──→ httpClient ──→ LLM API
                     ↑                                     │
                     │                               (stream response)
                     │                                     │
                     └──(tool result)── tools ←── tool_calls│
                              │                              │
                              └──(command)──→ 本地 shell     │
                              └──(file)─────→ 本地文件系统   │
```

## 5. 扩展性设计
- 新工具通过实现统一接口即可注册到 agentLoop
- 通信层可替换为其他协议（WebSocket、gRPC）
- 配置驱动，无需重新编译即可调整 Agent 行为
