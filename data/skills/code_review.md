# L3 代码审查清单

## 结构检查
- [ ] 新类是否有必要，是否违反单一职责
- [ ] 是否使用了 struct 而非不必要的 class
- [ ] 成员变量是否符合命名规范（m_ 前缀）
- [ ] 文件命名是否符合 CLF 前缀规范

## 安全性检查
- [ ] 无裸指针（使用智能指针 / RAII）
- [ ] 无内存泄漏路径
- [ ] 输入参数有合法性校验
- [ ] 网络请求有超时和错误处理

## 可维护性检查
- [ ] 函数职责单一，长度合理
- [ ] 无重复代码（优先抽象复用）
- [ ] 错误处理路径完整
- [ ] 无注释掉的代码
- [ ] 注释说明"为什么"而非"做什么"

## 性能检查
- [ ] 无不必要的拷贝（使用 const& 或 std::move）
- [ ] 循环内无重复计算
- [ ] 热路径避免动态内存分配
