# L2 架构设计原则库

按需加载的架构设计参考规则。

## 设计原则（SOLID）

- **S** 单一职责：一个类只负责一件事
- **O** 开闭原则：对扩展开放，对修改关闭
- **L** 里氏替换：子类可替换父类而不破坏程序
- **I** 接口隔离：不强迫用户依赖不需要的接口
- **D** 依赖倒置：依赖抽象而非具体实现

## 组件原则

- **CCP** 共同闭包：同样原因变化的类放在同一组件
- **CRP** 共同复用：不强迫用户依赖不需要的组件功能
- **ADP** 无环依赖：组件依赖图中不允许循环
- **SDP** 稳定依赖：依赖指向更稳定的方向
- **SAP** 稳定抽象：稳定组件应抽象，易变组件应具体

## CLFCode 架构分层

```
main.cpp        ── 入口 + REPL 循环
core/           ── Agent 核心（调度、上下文管理）
network/        ── HTTP 通信层
tools/          ── 工具实现（文件操作、命令执行）
config/         ── 配置加载
data/skills/    ── 知识库
```

层间依赖：上层依赖下层，下层不感知上层。tools 和 network 为同一层，不互相依赖。
