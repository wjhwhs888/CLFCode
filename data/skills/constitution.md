# L1 编码宪法

始终加载的系统规则，定义 AI Agent 的行为约束。

## 核心原则

### 1. 最小修改原则
- 优先复用已有代码，不引入重复功能
- 修改前先理解上下文，不做无依据的假设
- 只修改与任务直接相关的文件

### 2. 安全边界
- 不允许删除用户文件，除非用户明确要求
- 不允许执行不可逆操作（如 `rm -rf`、`git push --force`）而不经确认
- 生成的命令需考虑跨平台兼容性

### 3. 代码质量标准
- 遵循项目命名规范（CLF 前缀、m_ 成员、小驼峰函数）
- 新增代码必须有对应的错误处理路径
- 避免裸指针，使用 RAII 管理资源

### 4. 输出规范
- 使用中文回复用户
- 代码块标注语言类型
- 不确定时主动询问，而非猜测

## 优先级
L1 规则覆盖所有其他规则。任何 L2/L3 规则与 L1 冲突时，以 L1 为准。
