## 二、设计定案

### 2.1 合并规则（两路：新模板为基底 + 旧配置覆盖）

```
逐段逐键（嵌套两层：顶层 → 四段内）：
  新模板有、旧配置没有  → 补入新值          （新增参数更新进来 ✓）
  两边都有              → 旧配置值胜出      （已有参数不变 ✓）
  旧配置有、新模板没有  → 保留              （不删用户的东西）
```

- 段内值类型为对象（嵌套一层）→ 递归合并；标量/数组 → 旧值整体胜出（数组不做元素级合并——避免语义猜测）
- **模板默认值变更不传播**（如 security_mode edit→auto：旧配置显式写了 edit → 保留 edit）——保守语义（用户数据优先）；用户想换可手动改或 `/mode`
- 无法区分"用户删过某键"与"本来没有"——新模板会补回（可接受的副作用，记录）

### 2.2 应用点（install.ps1 恢复阶段改造）

现状恢复 = `$DATA_DIRS` 逐目录整体覆盖。改造后：

1. **config 目录**：恢复循环中特殊处理——
   - 备份里的 `agent_settings.json`（旧值）+ 新装目录的 `agent_settings.json`（新模板）→ 合并 → 写回新装目录
   - 备份里的 `agent_settings.local.json`（旧值，含 key）+ 合并基底 = **新模板 json**（local 的新键从模板补）→ 合并 → 写回
   - config 内其余文件（README 等模板文档）保持新装版本；备份里多余的旧文件**不再拷回**（模板文件随版本走）
2. **其余数据目录**（doc/contextHistory、doc/log、doc/debug）：维持整体覆盖恢复不动
3. **写回编码**：UTF-8 **无 BOM**（程序解析要求；`New-Object System.Text.UTF8Encoding($false)` + `[System.IO.File]::WriteAllText`）

### 2.3 边界与兜底

| 场景 | 行为 |
|------|------|
| 旧 json 解析失败（损坏/空） | 跳过合并——备份保留（救命副本）+ 新模板生效（现状语义） |
| 合并写回失败（磁盘/权限） | 抛异常 → 走既有 catch（回滚 + 备份保留） |
| 全新安装（无备份） | 合并函数不触发——新模板直接生效（现状语义） |
| 旧配置缺某段（如没有 agent 段） | 段级补入（新模板段整体） |

### 2.4 不做的

- 不做数组元素级合并（白名单/模型表等数组——旧值整体胜出）
- 不做配置版本号/迁移表机制（两路合并已覆盖"补新键"需求；显式迁移表留待未来有"改名/改结构"级变更时再加）
- 不动 upgrade.ps1（薄壳——拉取 install.ps1 执行，合并逻辑随 install 生效）

## 三、实施步骤（给实施者，可逐步核对）

### 步骤 1：合并函数 `Merge-ClfConfig`

install.ps1 函数区新增（约 40 行）：

```powershell
# 配置合并（两路：新模板为基底 + 旧配置覆盖）——
#   新模板有旧配置没有 → 补入；两边都有 → 旧值胜出；旧配置独有 → 保留
# 嵌套一层：顶层段（connection/chat_completions/agent/logging）内键级合并；
# 标量/数组整体取旧值（数组不做元素级合并——避免语义猜测）
function Merge-ClfConfig {
    param([object]$Base, [object]$User)   # Base=新模板, User=旧配置
    $result = @{}
    foreach ($k in $Base.PSObject.Properties.Name) {
        if ($User.PSObject.Properties.Name -contains $k) {
            $bv = $Base.$k; $uv = $User.$k
            if ($bv -is [System.Management.Automation.PSCustomObject] -and
                $uv -is [System.Management.Automation.PSCustomObject]) {
                $result[$k] = Merge-ClfConfig $bv $uv
            } else {
                $result[$k] = $uv          # 已有参数不变
            }
        } else {
            $result[$k] = $bv              # 新增参数补入
        }
    }
    foreach ($k in $User.PSObject.Properties.Name) {
        if (-not $result.ContainsKey($k)) { $result[$k] = $User.$k }
    }
    return [PSCustomObject]$result
}
```

### 步骤 2：config 目录恢复改造

恢复循环中 `config` 分支单独处理：

```powershell
foreach ($rel in $DATA_DIRS) {
    $srcPath = Join-Path $backupRoot $rel
    if (-not (Test-Path -LiteralPath $srcPath)) { continue }
    if ($rel -eq "config") {
        # 合并升级：旧值保留 + 新键补入（两个 JSON；其余模板文件保持新装版本）
        $utf8NoBom = New-Object System.Text.UTF8Encoding($false)
        foreach ($name in @("agent_settings.json", "agent_settings.local.json")) {
            $oldCfg = Join-Path $srcPath $name
            $newCfg = Join-Path $INSTALL_DIR $rel $name
            if (-not (Test-Path -LiteralPath $oldCfg)) { continue }
            try {
                $base = Get-Content -LiteralPath $newCfg -Raw -Encoding UTF8 | ConvertFrom-Json
                $user = Get-Content -LiteralPath $oldCfg -Raw -Encoding UTF8 | ConvertFrom-Json
                $merged = Merge-ClfConfig $base $user
                [System.IO.File]::WriteAllText(
                    $newCfg,
                    ($merged | ConvertTo-Json -Depth 5),
                    $utf8NoBom)
                Write-Host "  配置已合并（$name：旧值保留 + 新参数补入）" -ForegroundColor Gray
            } catch {
                # 旧配置损坏 → 跳过合并：新模板生效、备份保留救命副本
                Write-Host "  配置合并跳过（$name 无法解析，新模板生效；备份保留）" -ForegroundColor Yellow
            }
        }
        # 其余文件（README 等）保持新装版本；备份的旧文件不再拷回
    } else {
        $dstPath = Join-Path $INSTALL_DIR $rel
        New-Item -ItemType Directory -Path $dstPath -Force | Out-Null
        Get-ChildItem -Path $srcPath -Force | Copy-Item -Destination $dstPath -Recurse -Force
    }
}
```

## 四、风险与回退

- **回退**：合并逻辑局限在 config 分支——出问题删掉分支恢复整体覆盖（一行注释开关）
- **合并误伤**（旧值胜出掩盖新默认）——用户可接受（保守语义定案 §2.1）；如需传播某默认值变更 → 手动改配置（发布说明注明）
- **PowerShell 5.1 兼容**：ConvertFrom-Json/ConvertTo-Json -Depth 均可用 ✓（无 PS7 专属语法）
