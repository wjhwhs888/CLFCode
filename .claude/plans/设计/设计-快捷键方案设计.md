## 一、可直接实现（FTXUI 原生事件支持）

以下所有快捷键对应的 Event 常量均存在于 FTXUI v7 `event.hpp` 中，只需在 CatchEvent 中拦截即可。

| 功能 | 快捷键 | FTXUI Event 常量 | 说明 |
|------|--------|-----------------|------|
| 提交输入 | Enter | `Event::Return` | `multiline=false` + `on_enter` 为推荐方式 |
| 提交输入（备选） | Ctrl+D | `Event::CtrlD` | 标准 ASCII EOT，直接可拦截 |
| 换行（主） | Alt+Enter | ESC + Return（50ms timer 检测，见 §五 第 2 批） | 全终端兼容，行业标准 |
| 换行（备选） | Ctrl+N | `Event::CtrlN` | 全终端兼容 |
| 粘贴到输入区 | Ctrl+V | `Event::CtrlV` | 需配合 `CLFClipboard::read()` 获取剪贴板内容 |
| 复制全部内容 | Ctrl+Y | `Event::CtrlY` | 需配合 `CLFClipboard::write()` 写入剪贴板 |
| 中断 Agent | Esc | `Event::Escape` | 直接可拦截，调用 `m_interruptCb` |
| 关闭对话框 | Esc | `Event::Escape` | 确认栏激活时优先关闭弹窗（上下文判定） |
| 退出程序 | Esc Esc | `Event::Escape` | 需自定义双击计时逻辑（见 §3.1） |
| 切换安全模式 | Shift+Tab | `Event::TabReverse` | 直接可拦截，全局生效 |
| 内容区向上滚动 | 鼠标滚轮上 | `Mouse::WheelUp` | 需先 `screen.TrackMouse(true)` |
| 内容区向下滚动 | 鼠标滚轮下 | `Mouse::WheelDown` | 同上 |
| 内容区向上翻页 | PageUp | `Event::PageUp` | 直接可拦截 |
| 内容区向下翻页 | PageDown | `Event::PageDown` | 直接可拦截 |
| 跳到内容顶部 | Home | `Event::Home` | 直接可拦截 |
| 跳到内容底部 | End | `Event::End` | 直接可拦截 |
| 确认弹窗-确认 | Enter | `Event::Return` | 确认栏激活时拦截（上下文判定） |
| 确认弹窗-取消 | Esc | `Event::Escape` | 确认栏激活时拦截（上下文判定） |
| 确认弹窗-切换选项 | ← / → | `Event::ArrowLeft` / `Event::ArrowRight` | 确认栏激活时拦截 |

## 二、终端原生支持（代码无关，始终有效）

这些是 Windows Terminal / 终端模拟器层面的能力，FTXUI 应用**不需要也不能**干预。

| 操作 | 快捷键（Windows Terminal） | 说明 |
|------|--------------------------|------|
| 选中文本 | 鼠标拖选 | 在终端任意区域选择文字 |
| 复制选中文本 | Ctrl+Shift+C / 右键 | 将终端选中的文字复制到系统剪贴板 |
| 粘贴 | Ctrl+Shift+V / 右键 | 将剪贴板内容粘贴到终端 |
| 滚动查看历史 | 鼠标滚轮 / 终端滚动条 | 终端自身的回滚缓冲区（与 FTXUI 应用内滚动独立） |

## 三、需自定义逻辑（FTXUI 提供基础事件，自行实现状态机）

### 3.1 双击 Esc 退出

FTXUI 提供 `Event::Escape`，但没有「双击」概念。需自行实现：

- 记录上次 Esc 时间（`std::chrono::steady_clock`）
- 空闲且无弹窗时，两次 Esc 间隔 < 500ms → 触发 `/exit`
- Esc 其他场景（Agent 运行中、弹窗打开时）走各自逻辑，不计入双击

### 3.2 输入历史导航（↑/↓ 边界切换）

FTXUI 提供 `Event::ArrowUp` / `Event::ArrowDown`，Input 组件原生支持行内移动。需自行实现边界切换：

- 维护 `std::vector<std::string> m_inputHistory` 历史队列
- ↑ 在首行时：从历史取上一条 → 写入 `inputText` → 光标定位行末
- ↓ 在尾行时：从历史取下一条 → 写入 `inputText` → 光标定位行末
- 首行/尾行的判断：通过 `cursor_position` 和 `inputText` 中换行符的位置计算

## 四、不可实现（终端协议限制）

| 快捷键 | 原因 |
|--------|------|
| Ctrl+Enter | 终端发送字节 `0x0A`，与普通 Enter **完全相同**，FTXUI 解析为同一 `Event::Special({10})`，无法区分 |
| Shift+Enter | 同上，非 kitty keyboard protocol 终端无法区分 Shift 修饰的 Enter |

| Alt+Enter | 终端发送 `ESC` + `Return`，FTXUI 可识别为独立事件（Alt 前缀 ESC 字节）。**全终端兼容，唯一可靠的修饰 Enter** |

> **结论**：Enter 和 Ctrl+Enter/Shift+Enter 不可区分，但 **Alt+Enter 可以区分**（全终端兼容，行业标准）。建议 Enter = 提交，Alt+Enter = 换行（主），Ctrl+N = 换行（备选）。

#### 步骤 1.3：恢复 CatchEvent 框架 + 核心按键

文件：`src/CLFUI/CLFRepl.cpp`

```
auto handler = ftxui::CatchEvent(ui, [&](ftxui::Event e) {

    // === 1. 确认栏激活时（最小化处理，防卡死）===
    if (terminal && terminal->m_confirmActive) {
        if (e == ftxui::Event::Return) {
            terminal->m_confirmResult = true;
            terminal->m_confirmActive = false;
            terminal->m_confirmCv.notify_one();
            return true;
        }
        if (e == ftxui::Event::Escape) {
            terminal->m_confirmResult = false;
            terminal->m_confirmActive = false;
            terminal->m_confirmCv.notify_one();
            return true;
        }
        if (e == ftxui::Event::CtrlC) {
            // 确认栏激活时 Ctrl+C → 取消弹窗（不退出）
            terminal->m_confirmResult = false;
            terminal->m_confirmActive = false;
            terminal->m_confirmCv.notify_one();
            return true;
        }
        if (e == ftxui::Event::ArrowLeft || e == ftxui::Event::ArrowRight) {
            terminal->m_confirmSel = 1 - terminal->m_confirmSel;
            return true;
        }
        return true;  // 屏蔽其他所有按键（防文本泄露到输入框 + Tab 焦点切换）
    }

    // === 2. 提交 ===
    if (e == ftxui::Event::Return || e == ftxui::Event::CtrlD) {
        if (!inputText.empty() && !asyncSubmit.busy()) {
            auto text = inputText;
            inputText.clear();
            asyncSubmit.launch([&, text]() { submit(text); });
        }
        return true;
    }

    // === 3. 换行（仅 Ctrl+N, Alt+Enter 见第 2 批）===
    if (e == ftxui::Event::CtrlN) {
        input->OnEvent(ftxui::Event::Character("\n"));
        return true;
    }

    // === 4. Ctrl+C: 上下文感知分发 ===
    if (e == ftxui::Event::CtrlC) {
        // 确认栏激活时已在步骤 1 处理，此处只需区分 中断/退出
        m_escPending = false;  // 取消待处理的 Alt+Enter timer（防退出时 timer 残留）
        if (asyncSubmit.busy()) {
            // Agent 运行中 → 仅中断，不退出
            if (terminal && terminal->m_interruptCb)
                terminal->m_interruptCb();
        } else {
            // Agent 空闲 → 退出程序
            screen.ExitLoopClosure()();
        }
        return true;
    }

    // === 5. Esc: 仅做中断（双击退出 + Alt+Enter 见第 2 批） ===
    // 注：确认弹窗期间的 Esc 已在步骤 1 中处理（return true 屏蔽），此处无需重复
    if (e == ftxui::Event::Escape) {
        if (terminal && terminal->m_interruptCb)
            terminal->m_interruptCb();
        return true;
    }

    // === 6. Tab: 占位拦截（防止 FTXUI 焦点切换，后续实现补全） ===
    if (e == ftxui::Event::Tab) {
        // 仅在输入区聚焦时拦截 Tab（未来多组件场景下放行焦点切换）
        if (input->Focused()) {
            // 后续实现: 路径/命令补全
            if (!inputText.empty() && inputText[0] == '/') {
                // 命令补全（复用 dispatcher）
            } else {
                // 路径补全
            }
            return true;
        }
        return false;  // 非输入区 → 放行，让 FTXUI 正常处理焦点切换
    }

    // === 7. 模式切换 ===
    if (e == ftxui::Event::TabReverse) {
        cycleMode();
        return true;
    }

    // === 8. 滚动 ===
    if (scrollView.handleEvent(e))
        return true;

    return false;
});
screen.Loop(handler);
asyncSubmit.join();
if (m_escTimer.joinable()) m_escTimer.join();           // 第 2 批起生效（join timer 线程）
if (terminal) terminal->setScreen(nullptr);              // 防 ~CLFTerminal() 中 m_screen 悬空（batch 1 即生效）
```

#### 步骤 2.1：Alt+Enter 实现（timer 线程 + PostEvent）

问题：Alt+Enter = ESC + Return。如果 Esc 立即中断，则 Alt+Enter 永远无法触发（ESC 先被中断拦截）。

方案：ESC 事件到达时，不立即中断，启动 50ms timer 线程。50ms 内如果 Return 到达 → Alt+Enter 换行。50ms 超时（timer 触发）→ 中断。

实现：

```
CLFRepl.hpp 新增成员:
  std::chrono::steady_clock::time_point m_escTime;
  bool m_escPending = false;
  std::thread m_escTimer;  // 可 join 的 timer 线程（不使用 detach，防 screen 生命周期风险）

CLFRepl.cpp CatchEvent 中, 替换步骤 5（Esc）:

  // === Alt+Enter 检测 ===
  // 注：确认弹窗期间的 Esc 已在步骤 1 拦截，此处无需重复处理
  if (e == ftxui::Event::Escape) {
      // 启动延迟中断
      m_escPending = true;
      m_escTime = std::chrono::steady_clock::now();
      // 启动 timer 线程（join 前一次的，保证只有一个在跑）
      if (m_escTimer.joinable()) m_escTimer.join();
      m_escTimer = std::thread([this, terminal]() {
          std::this_thread::sleep_for(std::chrono::milliseconds(50));
          // 检查 screen 是否仍然存活（退出路径会置 m_screen=nullptr）
          if (terminal && terminal->m_screen)
              terminal->m_screen->PostEvent(ftxui::Event::Custom);
      });
      return true;  // 先消费 ESC，等 timer 决定
  }

  // Alt+Enter: ESC 后 50ms 内收到 Return
  if (m_escPending && e == ftxui::Event::Return) {
      m_escPending = false;
      input->OnEvent(ftxui::Event::Character("\n"));
      return true;
  }

  // Timer 触发：50ms 到期，无 Return → 中断
  if (e == ftxui::Event::Custom && m_escPending) {
      auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
          std::chrono::steady_clock::now() - m_escTime).count();
      if (elapsed >= 50) {
          m_escPending = false;
          if (terminal && terminal->m_interruptCb)
              terminal->m_interruptCb();
      }
      return true;
  }

  // 非 Return 事件到达时若 m_escPending → 立即中断（不等 timer）
  if (m_escPending) {
      m_escPending = false;
      if (terminal && terminal->m_interruptCb)
          terminal->m_interruptCb();
      // 必须吃掉事件，防止字符注入输入框
      return true;
  }

  // 重要: screen.Loop() 返回后必须清理（防 use-after-free）
  // 在 run() 的 screen.Loop(handler); asyncSubmit.join(); 之后增加:
  //   if (m_escTimer.joinable()) m_escTimer.join();
  //   if (terminal) terminal->setScreen(nullptr);  // batch 1 也建议加（防 ~CLFTerminal 悬空指针）
```

```
// ↑ / ↓ 边界检测
if (e == ftxui::Event::ArrowUp || e == ftxui::Event::ArrowDown) {
    int pos = inputOpt.cursor_position();  // 需要声明 cursorPos Ref

    // ↑ 在首行
    if (e == ftxui::Event::ArrowUp) {
        // pos==0 时 rfind('\n', -1) 会下溢为 SIZE_MAX, 必须先判断
        size_t lineStart = (pos == 0) ? std::string::npos
                                      : inputText.rfind('\n', pos - 1);
        bool atTop = (lineStart == std::string::npos);
        if (atTop && !m_inputHistory.empty()) {
            if (m_historyIndex == -1) {
                m_historyIndex = static_cast<int>(m_inputHistory.size()) - 1;
            } else if (m_historyIndex > 0) {
                m_historyIndex--;
            }
            inputText = m_inputHistory[m_historyIndex];
            cursorPos = static_cast<int>(inputText.size());  // 光标到末尾
            return true;
        }
    }
    // ↓ 在尾行
    if (e == ftxui::Event::ArrowDown) {
        size_t lineEnd = inputText.find('\n', pos);
        bool atBottom = (lineEnd == std::string::npos);
        if (atBottom && m_historyIndex != -1) {
            if (m_historyIndex < static_cast<int>(m_inputHistory.size()) - 1) {
                m_historyIndex++;
                inputText = m_inputHistory[m_historyIndex];
            } else {
                m_historyIndex = -1;
                inputText.clear();  // 回到空输入
            }
            cursorPos = static_cast<int>(inputText.size());  // 光标到末尾（与 shell 惯例一致）
            return true;
        }
    }
    // 非边界 → 不拦截, 让 Input 组件正常处理行内移动
    return false;
}
```

注意：`cursorPos` 必须在 Input 组件创建之前声明，且绑定到 `inputOpt.cursor_position`。此变更不影响第 1 批（无 cursor_position 时 Input 使用内部默认光标管理）。
