# 归档-安全策略

> 状态：✅ 已实现并验证 | 提交：e716af2

## 设计目标

`execute_command` / `write_file` 此前无任何限制，模型可任意执行命令。实现四模式安全策略（对标 Claude Code）。

## 设计决策

| 决策 | 结论 |
|------|------|
| 四模式 | Auto（放行）/ Analyze（写命令阻断）/ Edit（确认）/ Manual（确认） |
| 工具分级 | `CLFToolRisk::Read / Write / Command`（注册时声明） |
| 确认交互 | 回调注入（main.cpp 提供终端 y/n），CLFAgentLoop 不直接读终端 |
| 拒绝反馈 | 阻断/拒绝结果作为工具结果回传 LLM（模型自行处理） |
| 默认模式 | `edit`（配置 `agent.security_mode` 可改） |

## 行为矩阵

| 模式 | Read | Write | Command |
|------|:---:|:---:|:---:|
| auto | ✅ | ✅ | ✅ |
| analyze | ✅ | ❌ 阻断 | ❌ 阻断 |
| edit | ✅ | 🔔 确认 | 🔔 确认 |
| manual | ✅ | 🔔 确认 | 🔔 确认 |

## 实现内容

### 核心文件

| 文件 | 职责 |
|------|------|
| `CLFSecurityPolicy.hpp/.cpp` | 模式枚举 + `isAllowed(risk, needConfirm)` 判断 |
| `CLFAgentLoop.hpp/.cpp` | CLFTool 加 `m_risk`；executeTools 检查 + 确认回调 |
| `CLFBuiltinTools.cpp` | write_file=Write，execute_command=Command |
| `main.cpp` | 确认回调（y/n）+ `/mode` 命令 |

### 拒绝消息格式

- 模式阻断：`[Blocked by security policy (mode: X)] 当前模式禁止执行该操作`
- 用户拒绝：`[Denied by user] 用户拒绝了该操作`

## 验证

- `> 运行 dir`（edit 模式）→ 终端确认，n 拒绝 / y 放行 ✅
- `/mode analyze` → 命令直接阻断不询问 ✅
- `/mode auto` → 全放行 ✅
- 读操作任何模式不拦截 ✅
