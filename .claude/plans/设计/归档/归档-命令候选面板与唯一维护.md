## 一、背景与目标

用户需求：输入框输入 `/` 时，在输入框上方（"确认区"）展示所有支持命令；继续输入前缀实时过滤（`/c` → `/clear` 等）。

用户定案（2026-09-21 两问）：
1. **纯展示提示列表**——不劫持按键，不做 ↑↓ 选择与补全
2. **空格后收起面板**——内容含空格（已进入参数阶段）即不再显示

用户核心约束：**列表信息唯一维护**——触发调用与用户展示来源同一处，更新列表不需要多处同步。

## 三、设计定案

### 3.1 唯一权威源 = CLFCommandDispatcher 注册表

三个消费方全部从 `m_commands` 派生：

| 消费方 | 现状 | 方案 |
|---|---|---|
| 触发调用（handle 分发） | 已走注册表 ✅ | 不动 |
| /help "● 命令"段 | 硬编码第二份 ❌ | **改为遍历注册表动态生成** |
| 候选面板（新功能） | 无 | 走新增查询 `matchingCommands` |

新增命令 = 只改 `registerBuiltinCommands` 一处，分发、/help、候选面板三处自动同步。

### 3.2 新增查询 API（注册表查询职责归 Dispatcher）

```cpp
// CLFCommandDispatcher.hpp
// 前缀匹配查询（候选面板与 /help 展示用；注册表查询职责归 Dispatcher）
// 纯前缀语义：不含空格判定——空格收起属 UI 交互语义，在 ReplView 层判定
// example:
//   auto m = dispatcher.matchingCommands("/c");  // → /clear, /config, /context
std::vector<const CLFCommand*> matchingCommands(const std::string& prefix) const;
```

实现（`.cpp`）：线性扫描 `m_commands`，`m_name.compare(0, prefix.size(), prefix) == 0` 命中。13 项每帧扫描零性能顾虑。

### 3.3 /help 动态生成

- cmdHelp 的 "● 命令" 段（`CLFCommands.cpp:81-94`）删除硬编码，改为遍历注册表：
  - 行格式：`"  ⎿ " + 左对齐(name, 12 宽) + m_description`
  - 名字最长 8 字符（/version），12 宽对齐与现格式视觉一致
- **注册表访问通道**：cmdHelp 是 5 参标准 handler 拿不到注册表——用 `/plugin` 同款先例（`CLFCommands.cpp:542-551`）：注册时 lambda 捕获 dispatcher，把 `dispatcher.commands()` 传给 cmdHelp 静态函数
- **行为变化（用户已知情）**：/help 描述文本统一为注册表版本（§2.2 漂移处以注册表为准）；快捷键/确认弹窗两段（:63-79）是快捷键列表非命令列表，保持硬编码不动

### 3.4 候选面板（CLFReplView 渲染）

**判定（每帧渲染时读 m_inputText）**：
- 非空 && 首字符 `/` && 不含空格 → 命令模式
- 其余 → 空 Element 零占用（项目惯例，Tips 行同款）

**渲染落点**：`CLFReplView.cpp:417` render 的 vbox 中，`m_input->Render()` 之前、`thinSep()` 之上插入面板。内容区被压缩 N 行为 TUI 菜单自然行为（Claude Code 同款），可接受。

**面板形态**：
- 竖排列表，每条 = `bold(命令名) + dim(描述)`
- 整体 dim 弱化不抢焦点
- 折叠上限 6 行 + `"  … 还有 N 个"`（项目同款惯例——工具摘要折叠）
- 无匹配（如 `/x`）→ 不显示面板

**实现形态**：`CLFReplView` 新增私有方法 `buildCommandHintPanel(const std::string& inputText)`，返回 `ftxui::Element`。注册表构造后只读，渲染线程读安全（与 `modeName()` 同模式，ReplView 已有 `m_dispatcher` 访问点）。

### 3.5 责任分层（SOLID）

| 层 | 职责 | 不做 |
|---|---|---|
| CLFCommandDispatcher | 注册表持有 + 前缀查询（数据） | 空格判定、渲染 |
| CLFReplView | 命令模式判定（空格收起）+ 面板渲染 | 注册表细节 |
| cmdHelp | 遍历注册表排版输出 | 维护第二份清单 |

- 候选面板不写入历史、不写入会话 jsonl、零配置新增
- 折叠上限 6 行为常量，可调
