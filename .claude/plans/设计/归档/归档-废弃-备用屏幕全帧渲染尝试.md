# 设计-备用屏幕全帧渲染终端UI重构

## Context

经过多轮 DECSTBM 方案尝试，发现以下致命问题：
1. `\033[2J` 在 DECSTBM 下行为不可靠（部分终端只清滚动区）
2. 固定区坐标依赖 `contentBottom()` 动态计算，buffer 行数与屏幕实际行数不匹配
3. `showThinking` 可能覆盖固定区（硬编码清除11行）
4. confirm dialog 中 buffer 增长导致旧固定区残留

**参考 Claude Code**：使用备用屏幕缓冲区（`\033[?1049h/l`），不依赖 DECSTBM 做全帧渲染。

## 核心理念

```
启动 → 进入备用屏幕 → 全帧渲染(内容+固定区)
流式 → DECSTBM保护固定区 → 内容填充
流式结束 → 全帧渲染(紧凑)
退出 → 退出备用屏幕 → 原始终端恢复
```

## 架构变化

| 概念 | 旧方案 | 新方案 |
|:---|:---|:---|
| 屏幕 | 主终端 `\033[2J` 清屏 | **备用屏幕** `\033[?1049h` |
| 滚动 | DECSTBM | 流式期间 DECSTBM，其余时间全帧渲染 |
| 固定区 | `contentBottom()` 动态计算 | 全帧渲染时按实际内容高度 |
| 清屏 | `\033[2J`（不可靠） | 逐行 `\033[row;1H\033[K`（绝对定位） |
| 渲染 | 部分更新（增量） | **全帧重建**（清屏→内容→固定区） |

## 关键方法

```cpp
// === 备用屏幕 ===
enterAltScreen()   → \033[?1049h       // 启动
exitAltScreen()    → \033[?1049l       // 退出，恢复原始终端

// === 全帧渲染 ===
fullRender()       → 逐行清屏 → 打印buffer → renderFixedArea → 光标定位
                   // 初始化后、流式结束后、缩放后

// === 流式模式 ===
beginStream()      → 逐行清屏 → setSR(1,maxCB) → renderFixedArea → \033[H
                   // toContentArea() 替代
endStream()        → fullRender()
                   // submit()末尾 替代
```

## 数据流

```
[启动]
initLayout()
  ├─ enterAltScreen()
  ├─ 逐行清屏(1..H)
  └─ (不绘固定区)

printBanner()          → buffer + stdout (6行)

fullRender()           → 紧凑: 清屏 + buffer内容 + 固定区

[提交]
toContentArea()        → beginStream()
  ├─ 清状态, s_buffer.clear()
  ├─ 逐行清屏(1..H)
  ├─ setSR(1, maxCB)   // DECSTBM 保护固定区
  ├─ renderFixedArea() // 固定在底部
  └─ \033[H            // 光标到滚动区顶

scrollPrint()          → 流式输出 (不变)

[提交末尾]
endStream()            → fullRender()
  ├─ flushPending
  ├─ 逐行清屏(1..H)
  ├─ 顺序打印 buffer
  └─ renderFixedArea() // 紧跟内容

[退出]
restoreScrollRegion()
  ├─ exitAltScreen()   // 恢复原始终端
  └─ resetSR()
```

## 改动清单

### CLFTerminal.hpp
- 新增: `enterAltScreen()`, `exitAltScreen()`, `fullRender()`, `beginStream()`, `endStream()`
- 移除: `compactLayout()` (废弃)
- 保留: `lowerSepRow/modeRow/confirmRow` 内容相对定位

### CLFTerminal.cpp
- **新增** `enterAltScreen()`: `std::cout << "\033[?1049h" << std::flush`
- **新增** `exitAltScreen()`: `std::cout << "\033[?1049l" << std::flush`
- **新增** `fullRender()`: 逐行清屏 → 顺序打印buffer(从行1) → renderFixedArea
- **新增** `beginStream()`: 逐行清屏 → setSR → renderFixedArea@bottom → \033[H
- **新增** `endStream()`: = fullRender()
- **修改** `initLayout()`: enterAltScreen + 逐行清屏（不调 renderFixedArea）
- **修改** `toContentArea()`: = beginStream()
- **修改** `restoreScrollRegion()`: exitAltScreen + resetSR
- **修改** `redrawAll()`: = fullRender()
- **保留**: contentBottom 动态计算, showThinking/clearStatus(仅清oldSL行), hideConfirm(先算行号)

### CLFRepl.cpp
- `run()`: printBanner 后 `fullRender()` 替代 `compactLayout()`
- `submit()` 末尾: `endStream()` 替代 `compactLayout()`
- dispatch: `endStream()` 替代 `compactLayout()`

### 不动
- `CLFScrollBuffer` (m_pending 修复保留)
- `CLFAgentLoop`, `CLFConsole`, `CLFAnsi`

## 验证

1. 构建: `cmake --build cmake-build-debug -j6`
2. 运行 CLFCode:
   - 启动: banner + 紧凑固定区，一份无空白
   - 提交: 清屏 → 流式 → 紧凑固定区紧跟内容
   - 退出: 原始终端恢复（不残留 ANSI 状态）
3. 测试: `ctest --test-dir cmake-build-debug --output-on-failure -j6`
