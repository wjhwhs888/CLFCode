# 归档-配置体系

> 状态：✅ 已实现并验证 | 提交：ef2ddc9 → 3018ecd

## 设计目标

配置零硬编码，对齐 DeepSeek API 参数，本地 Key 安全存放。

## 设计决策

| 决策 | 结论 |
|------|------|
| 结构 | 四段：connection / chat_completions / agent / logging |
| API 对齐 | chat_completions 100% 覆盖 DeepSeek Chat API 参数 |
| Key 安全 | 模板 `agent_settings.json`（空 key）+ `.local.json`（真实配置，gitignore） |
| 加载优先级 | `.local.json` → 环境变量 → `agent_settings.json` |
| 路径 | `findProjectRoot()` 从 exe 向上找 CMakeLists.txt，所有路径基于项目根 |

## 配置结构

```json
{
    "connection": { "base_url", "api_key" },
    "chat_completions": {
        "model", "sub_model", "max_tokens", "temperature", "top_p",
        "frequency_penalty", "presence_penalty", "stop", "response_format",
        "stream", "thinking_level"
    },
    "agent": {
        "max_context_window", "max_tool_call_iterations", "context_compression",
        "max_response_delay_sec", "interaction_language", "security_mode"
    },
    "logging": { "level", "file", "console" }
}
```

## 实现内容

### 核心文件

| 文件 | 职责 |
|------|------|
| `CLFConfigLoader.hpp/.cpp` | JSON 解析 + 环境变量覆盖 + `findProjectRoot()` / `resolvePath()` |
| `CLFAgentLoop.hpp` | `CLFAgentConfig` 全字段定义（默认值与配置一致） |

### 环境变量覆盖

`CLF_API_KEY` / `CLF_API_BASE_URL` / `CLF_MODEL`（优先级高于配置文件）
