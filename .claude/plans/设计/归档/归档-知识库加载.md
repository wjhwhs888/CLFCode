# 归档-知识库加载

> 状态：✅ 已实现并验证 | 提交：1d17cfe

## 设计目标

让 Agent 感知 `data/skills/` 下的编码规则，L1 常驻、L2/L3 按需注入。

## 设计决策

| 决策 | 结论 |
|------|------|
| L1 编码宪法 | 始终注入 system prompt（与身份提示词合并） |
| L2/L3 规则 | 启动时加载到内存，`/skill` 命令按需注入 |
| 触发方式 | 手动命令触发（不用意图检测，简单可控 0 误判） |

## 实现内容

### 核心文件

| 文件 | 职责 |
|------|------|
| `CLFSkillLoader.hpp/.cpp` | 从目录加载 .md 文件到静态 map，按名查询 |
| `CLFAgentLoop.cpp` | `injectSystemPrompt()` 追加 constitution.md；`injectSkillToContext()` |
| `main.cpp` | 启动加载 + `/skill list` / `/skill <name>` 命令 |

### Skills 结构

```
data/skills/
├── constitution.md   # L1 编码宪法（始终注入）
├── architecture.md   # L2 架构设计原则
├── debug.md          # L3 调试工作流
├── code_review.md    # L3 代码审查清单
└── unittest.md       # L3 单元测试规则
```

## 验证

- 启动显示 `Skills loaded: 5` ✅
- `/skill list` 列出全部 skill ✅
- `/skill architecture` 注入后模型能引用 SOLID 原则 ✅
- 模型行为受 L1 约束（"不确定时主动询问"）✅
