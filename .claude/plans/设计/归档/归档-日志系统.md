# 归档-日志系统

> 状态：✅ 已实现 | 提交：de49a67

## 设计目标

诊断信息（Warning/Error/Fatal）此前散落各文件直接 `std::cerr`，无级别过滤、无时间戳、无文件输出。`logging` 配置字段早已存在但未实现。

## 设计决策

| 决策 | 结论 |
|------|------|
| 模式 | 单例（`CLFLogger::instance()`） |
| 级别 | Debug < Info < Warn < Error，低于配置级别丢弃 |
| 输出 | 文件（`logging.file`，基于项目根解析）+ 可选控制台 |
| 交互隔离 | 用户交互输出（REPL、流式回复）保留 `std::cout`，日志默认只写文件 |
| 线程安全 | mutex 保护 |

## 实现内容

### 核心文件

| 文件 | 职责 |
|------|------|
| `CLFLogger.hpp/.cpp` | 单例日志器：init / debug / info / warn / error |
| `CLFAgentLoop.hpp` | `CLFAgentConfig` 加 logging 字段 |
| `CLFConfigLoader.cpp` | 解析 logging 段 |
| `main.cpp` | 启动时 `init()` + 诊断输出替换 |

### 日志格式

```
[2026-07-31 11:30:00] [INFO] CLFCode starting, project root: E:\...
```

### 配置

```json
"logging": {
    "level": "info",
    "file": "clf_agent.log",
    "console": false
}
```

## 验证

- 启动后 `../../../../doc/log/clf_agent.log` 生成并写入启动日志 ✅
- 错误路径（如缺 API Key）写入日志 ✅
- `level` 调为 error 后 info 日志被过滤 ✅
- REPL 交互不被日志干扰（console: false）✅
