| 事实 | 位置 | 影响 |

## 二、实现清单

1. **CLFPluginManager 加 `listPlugins()`**：`std::vector<std::pair<std::string,std::string>>`（name, version，仅已加载）
2. **CLFCommandDispatcher**：构造加 `CLFPluginManager* pluginManager`（默认 nullptr）+ `std::function<bool()> isBusy`（默认空）；公开访问器
3. **CLFCommands.cpp**：`cmdPlugin(args, manager, isBusy, output)`：
   - `list`：遍历 listPlugins 输出 "● 已加载插件 N 个" + 每行 "⎿ name vX"（空 → "无插件（全静态构建）"）
   - `load <name>` / `unload <name>` / `reload <name>`：**isBusy() → 拒绝**（"✗ 对话进行中，回合结束后再操作"）；参数缺失 → 用法提示；结果成功 "✓ ..." 失败 "✗ ..."
   - 注册：`reg("/plugin", ...)` lambda 捕获 dispatcher
4. **CLFRepl**：构造加 `CLFPluginManager* pluginManager`（默认 nullptr）→ 传给 Dispatcher；isBusy lambda
5. **main.cpp**：Repl 构造传 &pluginManager
6. **/help** 加条目
