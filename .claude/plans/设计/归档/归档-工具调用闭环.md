# 归档-工具调用闭环

> 状态：✅ 已实现并验证 | 提交：ef2ddc9（核心）+ e716af2（安全策略）

## 设计目标

将 `CLFTools` 模块的真实工具（文件读写、命令执行）注册到 Agent，使模型能通过 tool_calling 机制实际操作系统资源。

## 设计决策

| 决策 | 结论 |
|------|------|
| Handler 适配位置 | `CLFBuiltinTools.cpp`（工具实现归属 CLFTools 模块） |
| Handler 签名 | `std::string(const std::string&)` — JSON 参数入，JSON 字符串出 |
| 返回格式 | `{"success": bool, "content"|"error": ...}`，命令额外带 `exitCode` |
| 风险分级 | `CLFToolRisk::Read / Write / Command`（配合安全策略） |

## 实现内容

### 内置工具清单（6 个）

| 工具 | 风险 | 参数 |
|------|:---:|------|
| `read_file` | Read | `path` (required) |
| `write_file` | Write | `path` + `content` (required) |
| `list_directory` | Read | `path` (默认当前目录) |
| `execute_command` | Command | `command` (required), `timeout` (默认 30) |
| `get_current_time` | Read | 无 |
| `echo` | Read | `message` (测试用) |

### 关键实现

- `CLFBuiltinTools::registerBuiltinTools()` 统一注册入口（main.cpp 一行调用）
- 每个 handler 内部：`json::parse(args)` → 调 CLFTools 函数 → 序列化结果
- 工具结果加入上下文：`addToolResult(toolCallId, name, content)`（tool 角色消息）

## 验证

- `> 运行 dir 命令` → execute_command 完整输出（含 stdout，BUG1 修复后）
