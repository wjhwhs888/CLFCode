# 归档-上下文管理

> 状态：✅ 已实现并验证 | 提交：a2dd9f4

## 设计目标

三个问题：system prompt 可能被截掉、token 估算对中文不准、长工具结果撑爆上下文。

## 设计决策

| 决策 | 结论 |
|------|------|
| System 保护 | `getMessages()` 中 system 消息分离，永不截断 |
| Token 估算 | 不引外部 tokenizer，字符启发式 |
| 长消息截断 | 工具结果超 8000 字符截断 + 标记 |
| 上下文压缩 | 不做（需 sub_model 摘要，后续阶段） |

## 实现内容

### Token 估算规则

- ASCII 字符：`size/4`（0.25 token/字）
- UTF-8 多字节（CJK 等）：按 lead byte 计数 ×1.5 token/字
- tool_calls 的 arguments / id / name 计入

### 截断策略

- system 消息：永不截断（第一遍收集，优先保留）
- 非 system：从新到旧累计 token，超出窗口停止
- 工具结果 > 8000 字符：截断 + `[truncated, original: N chars]` 标记

## 验证

- `/clear` 后 system 身份 + L1 宪法依然存在 ✅
- 多轮对话上下文不丢失 ✅
- 长工具结果不撑爆上下文 ✅
