# 归档-会话管理

> 状态：✅ 已实现 | 待验证

## 设计目标

极简会话管理：崩溃恢复 + 会话列表。不做搜索/索引/跨会话引用。

## 设计决策

| 决策 | 结论 |
|------|------|
| 存储目录 | `doc/contextHistory/`（gitignore 保护） |
| 文件命名 | `YYYY-MM-DD_HH-MM-SS.json`（时间戳防同日冲突）+ `_incomplete` 后缀 |
| 存储格式 | JSON：version / saved_at / title / messages[]（含 tool_calls 全字段） |
| 崩溃恢复 | 每轮对话后自动存 incomplete；启动检测询问恢复/丢弃 |
| 自动清理 | 启动时删除 30 天前的会话文件 |
| 恢复时 system | 跳过（身份由 Agent 重新注入，避免重复） |

## 实现内容

### 核心文件

| 文件 | 职责 |
|------|------|
| `CLFSessionManager.hpp/.cpp` | 会话文件管理：save/load/list/findIncomplete/promote/cleanupOld |
| `CLFContext.hpp/.cpp` | serialize()/restore() + appendMessage()（完整字段恢复） |
| `CLFAgentLoop.hpp/.cpp` | saveSession()/restoreSession() |
| `main.cpp` | 启动恢复提示 + 每轮自动存盘 + /exit 保存 + /history + 30 天清理 |

### 会话文件格式

```json
{
    "version": 1,
    "saved_at": "2026-07-31_14-30-05",
    "title": "首条用户消息（截断 50 字符）",
    "messages": [
        {"role": "user", "content": "..."},
        {"role": "assistant", "content": "...", "tool_calls": [...]},
        {"role": "tool", "content": "...", "tool_call_id": "...", "name": "..."}
    ]
}
```

### 生命周期

```
启动 → 检测 incomplete → 询问恢复(y: 载入/n: 删除)
每轮对话后 → saveSession(incomplete=true)
/exit → saveSession(false) 正式保存 + 删除 incomplete
崩溃 → 残留 incomplete → 下次启动提示
```

## 验证

- `/exit` 后 `doc/contextHistory/` 出现正式会话文件 ✅
- 强杀进程 → 重启 → 提示恢复 → y → 历史完整（含 tool_calls）✅
- `/history` 列出最近 10 条（时间 + 标题）✅
