# 归档-流式响应

> 状态：✅ 已实现并验证 | 提交：ef2ddc9

## 设计目标

SSE 逐 token 流式输出（打字机效果），tool_calls delta 分片累积。

## 设计决策

| 决策 | 结论 |
|------|------|
| 累积器 | `CLFStreamAccumulator`（header-only，独立类） |
| 流式/同步 | `runTurn` 双模式，由 `config.stream` 切换 |
| 输出 | 流式路径实时 `std::cout << chunk << std::flush`，返回空串避免重复 |
| tool_calls | 按 `index` 分组合并：id/name 首次设置，arguments 逐片拼接 |

## 实现内容

### SSE 解析流程

```
POST (stream:true) → 逐行回调
  ├── data: {"delta":{"content":"你好"}} → 实时打印
  ├── data: {"delta":{"tool_calls":[...]}} → accumulator 累积
  ├── data: {"finish_reason":"tool_calls"} → 立即 finalize（不依赖 [DONE]）
  └── data: [DONE] → markDone
```

### 关键实现

- `CLFStreamAccumulator::feedDelta()` 返回 content 增量（供实时显示）
- 收到 `finish_reason` 即 finalize tool_calls（BUG4 修复：防网络中断丢数据）
- `CLFHttpClient::postJsonStream()` 跨 chunk 行缓冲（BUG2 修复：防半行 JSON 丢失）
