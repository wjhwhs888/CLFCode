# 设计-项目结构重构

> 状态：设计中 | 创建：2026-08-04

## 1. 目标

将 `src/CLFCore/` 中 48 个文件按功能拆分为独立子模块，确保：
- 每个模块**功能单一**，修改一个不影响其他
- 依赖方向**自上而下**，无循环
- **死代码清除**
- **职责泄漏归位**（渲染的不做调度，调度的不做渲染）

## 2. 现状问题

| 问题 | 涉及文件 |
|:---|:---|
| CLFTerminal 上帝对象：渲染+状态+ANSI转发+三代API | CLFTerminal.hpp/cpp |
| CLFAgentLoop 上帝对象：编排+重试+UI发射+持久化+prompt | CLFAgentLoop.hpp/cpp |
| CLFToolExecutor 直接调 scrollPrint 渲染 | CLFToolExecutor.cpp |
| CLFCommandDispatcher 直接调 scrollPrint 渲染 | CLFCommandDispatcher.cpp |
| 死代码：CLFStreamProcessor、CLFErrorCodes、EventType×17 | 多个文件 |
| CLFAnsi 被 CLFTerminal 全量 re-export | CLFTerminal → CLFAnsi |
| 模式名称在三处硬编码 | CLFSecurityPolicy/CLFRepl/CLFCommandDispatcher |

## 4. 依赖关系

```
CLFTypes          ← 最底层，无项目依赖
  ↑
CLFNetwork        ← 依赖 CLFTypes
  ↑
CLFCore           ← 依赖 CLFTypes + CLFNetwork (仅接口)
  ↑
CLFTools          ← 依赖 CLFTypes + CLFCore
  ↑
CLFUI             ← 依赖 CLFTypes + CLFNetwork (ICLFHttpClient)
  ↑
main.cpp          ← 组装所有模块
```

## 6. Include 更新

所有 `#include "CLFCore/XXX.hpp"` 改为新路径。例如：
- `"CLFCore/CLFTypes.hpp"` → `"CLFTypes/CLFTypes.hpp"`

## 7. CMakeLists.txt 更新

```cmake
# CLFTypes (header-only + 小型 lib)
add_library(clf_types INTERFACE)
target_include_directories(clf_types INTERFACE ${CMAKE_CURRENT_SOURCE_DIR})

# 或如果有 .cpp:
add_library(clf_types STATIC CLFTypes/CLFEventQueue.cpp)
target_include_directories(clf_types PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})

# CLFNetwork (加入 ThinkingIndicator)
add_library(clf_network STATIC
    CLFNetwork/CLFHttpClient.cpp
    CLFNetwork/CLFThinkingIndicator.cpp
)
target_link_libraries(clf_network PUBLIC clf_types)

# CLFCore (精简)
add_library(clf_core STATIC
    CLFCore/CLFAgentLoop.cpp
    CLFCore/CLFContext.cpp
    CLFCore/CLFProtocolAdapter.cpp
    CLFCore/CLFConfigLoader.cpp
    CLFCore/CLFLogger.cpp
    CLFCore/CLFSecurityPolicy.cpp
    CLFCore/CLFSessionManager.cpp
    CLFCore/CLFMessageCodec.cpp
    CLFCore/CLFSkillLoader.cpp
    CLFCore/CLFEncoding.cpp
    CLFCore/CLFRetryPolicy.cpp
    CLFCore/CLFToolExecutor.cpp
)
target_link_libraries(clf_core PUBLIC clf_types clf_network)

# CLFUI (新)
add_library(clf_ui STATIC
    CLFUI/CLFAnsi.cpp
    CLFUI/CLFScrollBuffer.cpp
    CLFUI/CLFTerminal.cpp
    CLFUI/CLFConsole.cpp
    CLFUI/CLFRepl.cpp
    CLFUI/CLFCommandDispatcher.cpp
)
target_link_libraries(clf_ui PUBLIC clf_core clf_network)

# CLFTools
add_library(clf_tools STATIC
    CLFTools/CLFBuiltinTools.cpp
    CLFTools/CLFFileOps.cpp
    CLFTools/CLFCommandExec.cpp
)
target_link_libraries(clf_tools PUBLIC clf_core)

# main
add_executable(CLFCode main.cpp)
target_link_libraries(CLFCode PRIVATE clf_core clf_network clf_tools clf_ui ${CLF_OPENSSL_LIBS})
```

## 8. 实施步骤

1. **创建目录** — `CLFTypes/`, `CLFUI/`
2. **移动文件** — 按清单移动，`git mv` 保留历史
3. **拆分 ICLFHttpClient** — 从 CLFHttpClient.hpp 提取接口到独立文件
4. **更新所有 include** — 全局替换路径
5. **更新 CMakeLists.txt** — 按新结构重写
6. **删除 CLFStreamProcessor** — 清理死代码
7. **构建验证** — `cmake --build` + `ctest`
