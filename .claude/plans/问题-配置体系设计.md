# 问题-配置体系设计

## 最终方案

用户习惯：一次配好，很少改。只要 JSON 文件，不要环境变量覆盖。

## 设计决策

| 决策 | 结论 |
|:---|:---|
| 加载时机 | 启动时一次性加载 |
| 环境变量覆盖 | ❌ 不做 |
| 运行时改配置 | ❌ 不做（不需要 `/config` 命令） |
| API Key | 直接写在 `agent_settings.json` 中（单机本地使用） |
| 热重载 | ❌ 不需要 |

## 文件结构

```json
{
    "api": {
        "base_url": "https://api.deepseek.com",
        "api_key": "sk-xxxxx",
        "model": "deepseek-chat",
        "max_tokens": 8192,
        "temperature": 0.0
    },
    "agent": {
        "security_mode": "analyze",
        "max_tool_calls_per_turn": 16,
        "enable_thinking": true
    },
    "logging": {
        "level": "info",
        "file": "clf_agent.log"
    }
}
```

新增字段：`agent.security_mode` — 默认启动模式（auto / analyze / edit / manual）

## 安全提醒

`agent_settings.json` 包含 API Key，确保：
- 已在 `.gitignore` 中添加 `agent_settings.local.json` 作为本地覆盖
- 或者直接不提交 `agent_settings.json`（需同步调整 `.gitignore`）
