# 问题-工具调用闭环

## 背景
LLM 说"我需要读文件 / 执行命令" → Agent 执行 → 结果塞回上下文 → 再调 LLM。
这是 Agent 区别于聊天机器人的核心能力。

## 当前状态
- `CLFTool` 注册机制已有骨架（`registerTool`）
- `parseToolCalls` / `executeTools` 均为 TODO
- `runTurn` 仅执行单次 API 调用，不循环

## 待解决
1. **多轮循环**：LLM 连续请求多个工具，或根据工具结果再请求下一个
2. **tool_call_id 回传**：执行结果需带原始 call_id 回传 API
3. **中止条件**：LLM 不再请求工具（finish_reason = "stop"），循环结束
4. **错误回退**：工具执行失败时，错误信息需回传 LLM，让其尝试修正
5. **最大轮次**：防止无限循环（建议默认最多 16 轮 tool_call）
6. **权限确认**：涉及写文件、执行危险命令前是否需要用户确认

## 涉及的上下文结构变化
`CLFMessage` 需支持 `tool_calls`（assistant 消息中的 tool_calls 数组）和 `tool_call_id`（tool 消息中的回传标识）

## 涉及文件
- `src/CLFCore/CLFAgentLoop.cpp`（runTurn 改为循环）
- `src/CLFCore/CLFContext.hpp`（CLFMessage 扩展）
- `src/CLFTools/CLFFileOps.cpp`
- `src/CLFTools/CLFCommandExec.cpp`
