## 二、dsh 参考要点（裁减依据）

| dsh 做法 | 我们抄/简化 |
|---|---|
| 双拼写归一：`cached_tokens ?? prompt_cache_hit_tokens` | **抄**：一次到位（现只接 deepseek，未来接 OpenAI 兼容 provider 免返工） |
| 命中率 = cacheRead / prompt 输入 | **抄口径**：分母 = prompt_tokens（非 total） |
| 防虚报 100%（部分命中自动加精度） | **简化**：整数 floor——`cacheHit==prompt` 才 100%，否则 `floor(hit*100/prompt)` 永不虚报 |
| 会话累计 + 单回合明细两视图 | MVP 只做回合显示；/context 累计为增强 |
| 分母 = uncached+cacheRead+cacheWrite 三桶 | **不抄**（CLFCode 无 cacheWrite 概念需求，deepseek 缓存计费只需命中率） |

## 三、接入设计

### 3.1 捕获层（两处解析 + 字段）

**① `CLFStreamAccumulator`（流式）**
```cpp
// feedUsage 内追加（照现有"缺失保持原值"哲学）：
if (usage.contains("prompt_tokens_details") && usage["prompt_tokens_details"].is_object()
    && usage["prompt_tokens_details"].contains("cached_tokens")
    && usage["prompt_tokens_details"]["cached_tokens"].is_number())
    m_usageCacheHit = usage["prompt_tokens_details"]["cached_tokens"].get<int>();
else if (usage.contains("prompt_cache_hit_tokens") && usage["prompt_cache_hit_tokens"].is_number())
    m_usageCacheHit = usage["prompt_cache_hit_tokens"].get<int>();
// 字段/getter/reset 同步：m_usageCacheHit（默认 0）+ getUsageCacheHit()
```

**② `CLFProtocolAdapter::parseAssistantResponse`（同步）**：同逻辑 → CLFResponse `m_usageCacheHit`（默认 0）

### 3.2 回合落地与累计（AgentLoop）

- 流式/同步路径把 cacheHit 拷进 parsed（同 255-257 模式，pro 对齐同步路径落点）
- **MVP 不做会话累计变量**（只回合显示）；**增强**：`m_totalCacheHitUsed` 并行 m_totalTokensUsed（同 R3 规则——仅正常解析路径累计）

### 3.3 显示（MVP 一处）

**回合 summary 文案**（pro 取证最终拼装点：ToolExecutor:691 候选 / finishTurn summary 行候选）：
```
规则：usage 存在且有 cache 信息才显示（照 T11"无 usage 省略"gate）
  prompt>0 且 cacheHit>0 → 追加 " · 缓存命中 X%"
  cacheHit==prompt        → "缓存命中 100%"
  否则                    → floor(cacheHit*100/prompt)（永不四舍五入到 100）
  prompt==0 / 无 cache 字段 → 不显示（0 命中不误导：无 usage 信息时不宣称"0%"）
```

### 3.4 兼容决策

- **MVP 不进 jsonl**：回合 usage 若落 summary 行则不动格式（避免版本化）；仅 UI 回显
- 老会话/无 usage：既有省略 gate 覆盖，零显示回归

### 3.5 配置

- 无新配置项——跟现有 include_usage 开关走（非 deepseek provider 不发送则自然无数据）

## 五、测试

- **qa_CLFStreamAccumulator**：feedUsage 带 `prompt_cache_hit_tokens` / 带 `prompt_tokens_details.cached_tokens`（双拼写）→ getUsageCacheHit 正确；缺失保持原值；reset 归零
- **qa_CLFProtocolAdapter**：同步响应 usage 带 cache 字段解析（T10/S3-2 系列扩展）
- **qa_CLFToolExecutor（T11 扩展）**：progressSummary 有 cacheHit 追加"缓存命中 X%"；无 usage 省略（回归既有）
- **防虚报边界**：cacheHit==prompt→"100%"；cacheHit=prompt-1→floor 非 100；prompt=0→不显示
- **R3 回归**：中断路径 cache 不累计（若做增强）
- **实机**：dummy 端点无法产生真实 cache 字段 → mock 注入即可；真实 DeepSeek 连续同前缀请求第二次 cacheHit>0（可人工观测）
