# 问题-安全策略设计

## 最终方案（对标 Claude Code）

| 模式 | 名称 | 对标 | 读操作 | 写/命令 | 场景 |
|:---|:---|:---|:---:|:---:|:---|
| L1 | 自动模式 | Auto | ✅ | ✅ | 信任任务、批量重构 |
| L2 | 分析模式 | Plan | ✅ | ❌ | 架构设计、探索代码、出方案 |
| L3 | 编辑模式 | Accept Edits | ✅ | 🔔 | 日常开发：看代码不拦，改代码确认 |
| L4 | 手动模式 | Manual | ✅ | 🔔 | 陌生代码库、每步都确认 |

## 设计原则

1. **读操作永不限制**
2. **写和命令是同一风险**
3. **L2 直接阻断，返回拒绝原因**
4. **L3 编辑后报备，L4 每步确认**

## 模式切换

```
/mode auto    →  L1
/mode analyze →  L2（默认启动模式）
/mode edit    →  L3
/mode manual  →  L4
```

## 实现方式

新增 `src/CLFCore/CLFSecurityPolicy.hpp/.cpp`，Agent 执行工具前调用 `policy.isAllowed()`
