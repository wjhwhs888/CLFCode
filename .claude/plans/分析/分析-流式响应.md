# 问题-流式响应

## 背景
同步 POST 等完整响应，用户可能看十几秒空白。流式 SSE 逐 token 输出，体验是基础要求。

## 当前状态
- `CLFHttpClient::postJson()` — 同步，已实现
- `CLFHttpClient::postJsonStream()` — 流式，已实现骨架
- `CLFAgentLoop::runTurn()` — 当前只调用 `postJson`，未接流式
- `CLFHttpResponse` 结构体无流式标记

## 待解决
1. `runTurn` 中切换为 `postJsonStream` 调用
2. SSE 行解析：`data: {"choices":[{"delta":{"content":"..."}}]}` → 提取 content 增量
3. 流式中的 tool_calls 需要累积 delta 拼接（比文本复杂）
4. 终端逐字输出（`std::cout` 实时刷新）
5. 同步模式作为 fallback（网络不支持流式时降级）
6. 进度展示：首 token 延迟（TTFT）、token 速率

## 涉及文件
- `src/CLFCore/CLFAgentLoop.cpp`
- `src/CLFNetwork/CLFHttpClient.cpp`
- `src/CLFNetwork/CLFHttpClient.hpp`
