```
.claude/plans/
├── README.md                     # 本文件
│
├── 设计/                         # 详细设计方案（可照着编码）
│   ├── 设计-总体方案.md           # 系统架构总体设计
│   └── 归档/                     # 已实施完成的设计
│       └── 归档-API协议适配.md
│
├── 分析/                         # 问题分析（定方向，不定细节）
│   ├── 分析-工具调用闭环.md
│   ├── 分析-流式响应.md
│   ├── 分析-知识库加载.md
│   ├── 分析-上下文管理.md
│   ├── 分析-安全策略.md
│   ├── 分析-会话管理.md
│   ├── 分析-配置体系.md
│   └── 分析-测试策略.md
│
└── 测试/                         # 测试用例与验证记录
    └── （待填充）
```

## 分组说明

| 分组 | 前缀 | 粒度 | 用途 |
|------|------|------|------|
| **分析** | `分析-` | 方向级 | 识别问题、讨论方案方向、定大原则。**不定接口、不定数据结构** |
| **设计** | `设计-` | 实现级 | 详细方案：接口定义、类设计、算法伪代码、文件清单。可照着编码 |
| **归档** | `归档-` | 实现级 | `设计-` 实施完成后移入 `设计/归档/`，记录实际实现 |
| **测试** | `测试-` | 用例级 | 测试用例、验证步骤、结果记录 |

## 工作流

```
分析-XXX.md  →  设计-XXX.md  →  实施  →  归档-XXX.md
   ↑                ↑                    ↑
 定方向           定细节             记录实际实现
```
