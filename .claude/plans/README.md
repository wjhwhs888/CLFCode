## 分组说明

| 分组 | 前缀 | 粒度 | 用途 |
|------|------|------|------|
| **分析** | `分析-` | 方向级 | 识别问题、讨论方案方向、定大原则。**不定接口、不定数据结构** |
| **设计** | `设计-` | 实现级 | 详细方案：接口定义、类设计、算法伪代码、文件清单。可照着编码 |
| **归档** | `归档-` | 实现级 | `设计-` 实施完成后移入 `设计/归档/`，记录实际实现 |
| **测试** | `测试-` | 用例级 | 测试用例、验证步骤、结果记录 |

## 工作流

```
分析-XXX.md  →  设计-XXX.md  →  实施  →  归档-XXX.md
   ↑                ↑                    ↑
 定方向           定细节             记录实际实现
```
