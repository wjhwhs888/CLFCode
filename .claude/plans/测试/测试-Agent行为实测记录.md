## 判定口径（读用例前先看）

| 类别 | 含义 | 强度 |
|------|------|------|
| **不得出现** | 负向断言：出现即 FAIL | **强（主力）** |
| **必须出现** | 正向断言：缺失即 FAIL（尽量少用，关键词即可） | 中 |
| **预算** | 工具调用数 / token / wall-clock 上限，超限即 FAIL | 强 |
| **通用不变量** | 见下节，**所有用例都要判** | 强 |

**状态图例**：`未测` · `通过` · `未通过` · `待复测` · `弃用`
**判定事实源**：会话 jsonl（工具序列/参数/token）· `doc/log/clf_agent.log` · stdout · 进程退出码 · `git status --porcelain`

## 通用不变量（每例都判，不重复写在用例里）

1. **不原样重试**：同一条命令**连续重复 ≤ 1 次**（历史四次实证：`head`、`dir`、`& "path"`、`mytoolctl` 都因此重试过）；
2. **协议闭合**：声明数 == 结果数；
3. **工作区干净**：`git status --porcelain` 无新增（无临时文件残留）；
4. **成本门**：超 wall-clock(180s) / token(60k) 即中止并判 FAIL——**不许无限轮询**。

## 一、平台认知

### `P-01` 平台自述
- **提示词**：你现在所在的机器是什么系统？用的哪个 shell？有哪些常用命令在这台机器上不能用？
- **必须出现**：`cmd.exe`；不可用命令清单（≥5 个，取自 `bash grep sed awk ls cat rm cp mv xargs diff uname`）
- **不得出现**：`\| head`、`ls -`、`grep -`（作为"本机可用"来陈述）
- **预算**：工具调用 **≤2**；token **≤20k**
- **判定事实源**：jsonl（工具序列 + token 统计）+ stdout
- **实测（2026-09-23）**：内容**正确**（准确答出 Windows 11 / cmd.exe / 逐个 `where` 验证的不可用清单 / GBK 代码页），但为得到答案**实测 15+ 条命令、token 增量约 400k**
- **状态**：`未通过`（仅预算项不达标 → 正是 M2/M3 要省的成本）
- **关联**：`X5` · `M2` · `M3`

- **实测（2026-09-23）**：通过（`git log --oneline -8 --no-decorate`）

### `H-02` 目录按时间最新 5 个

### `H-03` 找 TODO 只看前 20 行
- **提示词**：找出项目里所有包含 TODO 的地方，结果只给我前 20 行
- **不得出现**：`grep -r`、`\| head`

- **判定事实源**：jsonl（工具序列）+ 单例 token 统计

- **提示词**：用 PowerShell 一行命令，列出当前目录下最大的 5 个文件（按大小排）

- **实测（2026-09-23）**：通过

### `H-07` PowerShell 看 PATH 前 3 项
- **提示词**：用 PowerShell 看看 PATH 环境变量里前 3 个目录
- **不得出现**：任何 ✗

- **状态**：`通过`（X7 未复现的证据之二）

### `H-08` 跑 Program Files 下 exe 的 --version
- **提示词**：找到并运行 `C:\Program Files` 下某个 exe 的 `--version`
- **不得出现**：命令以 `&` 开头；stdout 含 `此时不应有 &`
- **实测（2026-09-23）**：**失败**——模型写了 `& "C:\Program Files\nodejs\node.exe" --version`（**`&` 是 PowerShell 调用运算符，发给 cmd 了**）→ ✗ ×2 + **原样重试一次**；随后自己纠正为 `powershell -Command "& '…'"` 才成功
- **状态**：`未通过`
- **关联**：`X5` · `X4` · `M2` · `M3`

### `H-09` PowerShell 输出带引号的话
- **提示词**：用 PowerShell 输出一句带引号的话，比如 `hello`
- **不得出现**：无关联的"不是内部或外部命令"
- **实测（2026-09-23）**：通过（`\"` 嵌套未破裂）；但模型**误判自己第一次的输出**，做了对照实验才自我纠正（4 轮约 150k token）→ **观察项**
- **状态**：`通过`（观察：自我纠错能力在，成本偏高）

## 三、失败信号（误 ✗ 与重试）

### `S-01` 列目录过滤 js（无匹配）
- **提示词**：列一下目录内容并过滤出 js 文件，同时告诉我当前目录
- **不得出现**：用户可见状态 ✗；原样重试
- **判定事实源**：stdout（显示态）+ jsonl（是否重复）
- **实测（2026-09-23）**：`cd & echo ---- & dir /b *.js 2>&1` → "找不到文件" → **✗ + 原样重试一次**
- **状态**：`未通过`
- **关联**：`X8` · `X13` · `X4` · `M1b` · `M1c` · `M9`

### `S-02` 列目录只留 .json（有匹配）
- **提示词**：列一下目录内容，只保留 .json 的文件
- **不得出现**：任何 ✗
- **实测（2026-09-23）**：通过（`dir /b /a *.json` 命中）
- **状态**：`通过`（**反向对照**：证明 S-01 的 ✗ 只在"无匹配"时出现）

### `S-03` 跑不存在的命令并解释
- **提示词**：执行一个本机不存在的命令（比如 `mytoolctl --help`），然后告诉我为什么失败、正确该怎么做
- **必须出现**：错误类型为"命令不存在"（`errorKind=not_found` 或等价表述）
- **不得出现**：`%ERRORLEVEL%`、`if errorlevel`（自己挖退出码）；原样重试
- **预算**：工具调用 ≤3
- **实测（2026-09-23）**：✗ + **原样重试一次**；随后**用 6 条命令**自己挖退出码（`echo ---exitcode=%ERRORLEVEL%`、`where … & echo where-exitcode=…`、`if errorlevel 1 (…)`、`cmd /v:on /c "…!var!"`）
- **状态**：`未通过`
- **关联**：`X13` · `X4` · `M1c` · `M9`

### `S-04` 有没有装 ffmpeg（无匹配族）
- **提示词**：看看本机有没有装 ffmpeg
- **不得出现**：把"未找到"标成 ✗；`where /R C:\`／全盘搜索
- **预算**：工具调用 ≤4；wall-clock ≤90s
- **实测（2026-09-23）**：多条 ✗（`Get-Command ffmpeg` exit 1、`Get-ChildItem 'C:\Pr…'` exit 1、`where /R D:\ ffmpeg.exe` 未找到）；并**全盘搜索 C:\ 与 D:\**（51 s、约 33.7k token）
- **状态**：`未通过`
- **关联**：`X8`（范围比 `dir` 更广：**PowerShell 查询命令也在内**）· `M1c`

### `S-05` 找不存在的标记
- **提示词**：在 src 文件里找一下包含 `ZZZ_NO_SUCH` 的行
- **必须出现**：零匹配时**做对照搜索**证明工具有效（好行为）
- **不得出现**：任何 ✗
- **实测（2026-09-23）**：通过（主动对照 `FS_PERMISSION_DENIED` 有命中，再用 PowerShell 交叉验证）
- **状态**：`通过`

### `S-06` 只读进程查询不得触发危险确认
- **提示词**：（间接）中断后追问"后台那个测试还在跑吗"
- **不得出现**：`命中危险命令模式，需确认`
- **实测（2026-09-23）**：**失败**——查进程的命令触发危险确认，打断流程（该命令全文未留存）
- **状态**：`未通过`
- **关联**：`X10`

## 四、成本纪律

### `C-01` 跑测试给最后 20 行
- **提示词**：跑一遍测试，把最后 20 行结果给我
- **不得出现**：`start /b`、`Start-Process`、临时 `*.tmp.cmd`（伪后台）；无限轮询
- **预算**：wall-clock ≤180s；token ≤60k；工具调用 ≤6
- **实测（2026-09-23）**：`start /b cmd /c "…"` 被 cmd 拆分 → 改写临时 `.cmd` + `Start-Process` → 每 60 s 轮询（**单轮 +16k token**），**用户手动中断止损**
- **状态**：`未通过`
- **关联**：`X14`（无后台能力 + 无长任务纪律）

### `C-02` 中断后回看上次输出
- **提示词**：刚才那个命令的完整输出再给我看一遍
- **不得出现**：重复执行昂贵命令；危险确认误报
- **必须出现**：说明"输出不可得及其原因"
- **实测（2026-09-23）**：说明了原因（"那条命令被中断的，输出没留下来"）✔；但**触发危险确认误报**（见 `S-06`）
- **状态**：`未通过`（因误报）
- **关联**：`X10`

## 更新约定

1. **只追加**：新用例编号顺延；废弃的**保留并标 `弃用` + 理由**（取证链不删）；
2. **每例必须可判定**：没有明确 PASS 判据的用例不许进本文件（"感觉对"不算）；
3. **负向优先**：能写成"不得出现"的，不要写成"必须出现"；
4. **实测要留证据**：命令原文 + 现象 + token/耗时（人工跑完就补，别事后回忆）；
5. **状态随实测更新**：修完后标 `待复测`，复测通过再标 `通过`。
