## 3. 关键设计决策

### 3.1 CLI vs GUI
- **决定**：纯 CLI，不做 GUI
- **影响**：终端流式输出（`\r` 更新 / 逐字打印），无需事件循环
- **状态**：✅ 已定

### 3.2 Context 持久化
- **决定**：`doc/contextHistory/` 下按日期存 JSON
- **格式**：nlohmann/json 序列化 `std::vector<CLFMessage>`
- **命名**：`2026-07-24_session.json`，同日多次追加 `-2`、`-3`
- **恢复**：启动时可选加载历史会话
- **状态**：✅ 已定

### 3.3 安全策略 — ✅ 已定

按**工作模式**区分（对标 Claude Code）：

| 模式 | 名称 | 对标 | 读操作 | 写操作/命令 |
|:---|:---|:---|:---:|:---:|
| L1 | 自动模式 | Claude Code Auto | ✅ | ✅ |
| L2 | 分析模式 | Claude Code Plan | ✅ | ❌ 直接拒绝 |
| L3 | 计划模式 | — | ✅ | 🔔 每次确认 |

- 读操作永不限制
- 写操作和命令执行统一视为"高风险操作"
- L2 直接阻断不询问，返回拒绝原因，不走确认流程

### 3.4 开发节奏
- **决定**：架构先行 → 设计闭环 → 阶段验证 → 编码
- **状态**：✅ 已定
